Key Improvements

1.

Expandable Row Details

Click any row to expand a structured detail panel below it

2.

Details Summary Column

Replaces truncated UUID/Checksum columns with a human-readable summary (version + file size for uploads, reason for deletes)

3.

Structured Key-Value Layout

Details shown as labeled fields in a grid instead of raw JSON

4.

Full ID & Checksum Display

No more truncation — full values shown with copy buttons

5.

Color-Coded Panels

Blue gradient header for uploads, red for deletions — instant visual distinction

6.

Deletion Reason Card

Reason shown in a highlighted card — not hidden in JSON
